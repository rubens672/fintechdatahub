### Esecuzione Automatica CI/CD tramite Cloud Build

#### 1. Avvio manuale di Cloud Build da CLI
Per inviare la build a Cloud Build che eseguirà Maven test, Skaffold build e creerà la release in Cloud Deploy:
```bash
gcloud builds submit \
  --region=$REGION \
  --config=cloudbuild.yaml \
  --substitutions=_REGION=$REGION

```

#### 2. Creazione del Cloud Build Trigger (per esecuzione automatica su Git Push)
Per far scattare la build ed il deploy in automatico a ogni push sul branch `main`:
```bash
gcloud builds triggers create github \
  --name="fintechdatahub-connect-trigger" \
  --repo-name="fintechdatahub" \
  --repo-owner="YOUR_GITHUB_USERNAME" \
  --branch-pattern="^main$" \
  --build-config="fintechdatahub-connect/cloudbuild.yaml" \
  --region=$REGION
```

#### 3. Salvataggio e Persistenza di artifacts.json su GCP
- **Durante la Build**: Il file `artifacts.json` viene salvato nel filesystem condiviso temporaneo `/workspace` del container di Cloud Build, permettendo allo Step 3 (`cloud-deploy-release`) di leggerlo direttamente dallo Step 2 (`skaffold-build`).
- **Persistenza su Cloud Storage**: A fine build, grazie alla sezione `artifacts: objects:` di `cloudbuild.yaml`, il file viene salvato automaticamente in modo permanente nel bucket Cloud Storage:
  `gs://${PROJECT_ID}_cloudbuild/builds/$BUILD_ID/artifacts.json`
